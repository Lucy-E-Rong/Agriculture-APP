# FarmScout 0.1.0

Release type: personal independent demo baseline

## Demonstrated workflow

1. User opens the Expo mobile app or hosted web demo.
2. User passes the demo access-code check.
3. User selects an image from the device.
4. The client resizes/compresses it to JPEG and sends it to FastAPI.
5. FastAPI calls Gemini Developer API.
6. A structured lettuce assessment is returned and rendered.

The user manually confirmed that image upload and analysis work.

## Included

- Mobile/web app shell and navigation.
- Gemini and Local GPU VLM selector UI.
- Hosted Gemini analysis path.
- Structured analysis result UI.
- English/Chinese switch.
- Access-code gate.
- Mock dashboard, crop, location, and report content.

## Not included as working product behavior

- Persistent scan history.
- Image/result storage.
- Real dashboard statistics.
- Real crop/location management.
- Database-backed reports.
- Seven-day audit record.
- Configured deployed Local GPU VLM endpoint.
- User accounts and production privacy controls.
